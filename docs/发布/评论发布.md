# 基础发布

只针对帖子本身时，parent_comment_id为null，Request body参考创建帖子，不过我不打算写发布图片了。

# 针对评论的发布

需要填入parent_comment_id，即目标评论的 "comment_id"
具体效果实现方面，点击目标评论的评论键后，会获取目标评论的comment_id，同时相当于直接点击input输入框一样弹出键盘。

# 默认图片

未上传图片时，会进入到封面图加工页面
中间是模板图选择（滑动选择），同时支持实时文字预览，从三张模板图上选择一张
靠下是标题输入框，默认title继承自上一个发布页面.
最后底部是发布

使用react-native-view-shot这个库，选择好图片然后正确拼接后，使用库进行保存图片到draftimage上，然后继续上传。
对于标题的覆盖，只选取前8字，超出8字则加上...
